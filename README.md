# FitLog

**FitLog** es una aplicación pensada para llevar un registro de **sobrecarga progresiva** en el gimnasio: pesos, repeticiones, series y evolución de cada ejercicio a lo largo del tiempo.

## Estado actual del proyecto

En desarrollo temprano. Por ahora está implementado:

- Backend en **.NET 10.0.112**
- Infraestructura con **Docker Compose**, que levanta un contenedor de **PostgreSQL 16 (alpine)** para la base de datos

## Tech Stack

| Componente     | Tecnología          |
|----------------|---------------------|
| Backend        | .NET 10.0.112        |
| Base de datos  | PostgreSQL 16 (alpine) |
| Infraestructura| Docker Composes      |

## Requisitos previos

- [.NET SDK 10.0.112](https://dotnet.microsoft.com/download)
- [Docker](https://www.docker.com/) y Docker Compose
